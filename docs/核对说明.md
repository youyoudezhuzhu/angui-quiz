# 题库核对说明（125 条原始条目 → 119 道唯一题）

结论：**没有漏题。** 125 条原始条目全部能对上；其中 **6 条是完全重复**，去重后是 **119 道唯一题**。
练题网页、搜题 App、记忆手册都包含这 119 道题；导入 Excel 是 117 道选择题（2 道问答题格式不支持）。

## 一、125 条是怎么算出来的

| 来源文件 | 原始条目 | 去重后 |
| --- | --- | --- |
| 副本28.变电检修（B）.xlsx | 118 行 | 117 行（删 1 条内部重复） |
| 副本抽考题库（读图5选2）.xls | 5 行 | 0 行（5 条都与 xlsx 完全重复） |
| 问答题（2选1）.doc | 2 题 | 2 题 |
| **合计** | **125** | **119** |

119 道唯一题 = 单选 103 + 读图 14 + 问答 2。

## 二、6 条重复具体是哪几条

判定标准：题干、全部选项、答案、解析**逐字一致**（读图题还核对图片文件名）。

| 保留的条目 | 被合并的重复条目 | 说明 |
| --- | --- | --- |
| xlsx 第 96 行（序号 95） | xlsx 第 98 行（序号 97） | 题干“图上有（ ）违章行为。”，答案 D，图片同为“国网公司严重违章第18条.jpg” |
| xlsx 第 62 行（序号 61） | xls 第 2 行（试题 ID 1） | 5 条 xls 题全部是 xlsx 的原样副本 |
| xlsx 第 67 行（序号 66） | xls 第 3 行（试题 ID 2） | 同上 |
| xlsx 第 68 行（序号 67） | xls 第 4 行（试题 ID 3） | 同上 |
| xlsx 第 72 行（序号 71） | xls 第 5 行（试题 ID 4） | 同上 |
| xlsx 第 74 行（序号 73） | xls 第 6 行（试题 ID 5） | 同上 |

> 所以 xls 的 5 道“读图 5 选 2”并不是新增题，而是 xlsx 里 14 道读图题中的 5 道；
> 也就是说，读图题总数是 **14 道**（xlsx 里），不是 14+5=19 道。

## 三、各交付物到底放了多少题

| 交付物 | 题数 | 说明 |
| --- | --- | --- |
| 练题网页 | 119 | 103 单选 + 14 读图 + 2 问答 |
| 搜题 App | 119 | 同上 |
| 记忆手册 | 119 | 同上（103 单选/14 读图在速查表，2 问答单列） |
| 导入 Excel | 117 | 只有选择题（103 单选 + 14 读图）；问答题格式只支持 A-G，放不进 Excel，另给 `问答题_参考答案.txt` |

> 你看到“Excel 就 118”：xlsx **原始表**确实是 118 行，但其中第 96/98 行是同一道题；
> 我们给你的**导入 Excel**是去重后的 117 道选择题（不含 2 道问答题，因为格式不支持）。

## 四、逐条核对表

`题库核对表.xlsx` 共 3 个工作表：

1. **125条逐条核对**：125 行一条不落，列出每条的来源文件、行号、原始编号、题干、答案、处理结果、对应唯一题，
   以及“网页 / 搜题App / 导入Excel / 记忆手册”四列是否包含（重复条目标注“是（已合并）”）；
2. **重复明细**：6 组重复的保留/被删对照；
3. **核对结论**：上述统计汇总。

可以用“处理结果”列筛选：
- “保留（唯一）” = 119 行；
- “重复，合并到……” = 6 行。

## 五、说明

- 14 道读图题的原题配图没有随题库文件提供（xlsx/xls 内也没有内嵌图片），所以网页/App 里标注“配图缺失”；题目本身都在。
- 网页/App 的题号（第 N 题）是去重后重新编号的 1–119；核对表同时给出“原始编号”，方便回源文件对照。
- 如果你想要一份“125 条原样、含重复”的 Excel 用于自己核对，也可以再生成；但导入刷题不建议保留重复题。
